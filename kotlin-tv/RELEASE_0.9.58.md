## 这一版改了什么

- **播放器的那块黑遮罩改成透明**。Media3 的 `PlayerView` 里有一块默认可见的黑色遮罩（`exo_shutter`），盖在整个画面区上面。切集时它会先盖黑，等新的一集出第一帧才掀开。这块遮罩改成透明之后，切集不会再多盖一层黑。
- **其它一个字没动**。0.9.52 的全部内容原样保留：预取不再跟画面抢带宽、长关键词搜索、弹幕、遥控器焦点落点。

相对 0.9.52，**代码差异只有一行**：

```diff
- setKeepContentOnPlayerReset(true); setShutterBackgroundColor(Color.BLACK); setShowBuffering(PlayerView.SHOW_BUFFERING_ALWAYS)
+ setKeepContentOnPlayerReset(true); setShutterBackgroundColor(Color.TRANSPARENT); setShowBuffering(PlayerView.SHOW_BUFFERING_ALWAYS)
```

## 切集黑屏：查到了什么，为什么这一版没治好

自动连播切到下一集时黑一下。这件事查了一轮，结论写在下面 —— **这一版没有治好它**，别把「遮罩透明」当成黑屏已经修好。

### 黑幕是怎么来的

读 Media3 1.8.0 的 `PlayerView` 源码（`PlayerView.java` + `exo_player_view.xml`）能确认三件事：

1. `exo_shutter` 在布局里是 `android:background="@android:color/black"`，**默认可见**，铺满画面区。
2. `updateForCurrentTrackSelections()` 的分支是这样的：**轨道全空**（播放器刚 stop/reset、还没 prepare）时直接 return，**不动**幕布；而**轨道非空但视频轨还没选中**（切集时音频轨先选中、解码器还没建好）时调用 `closeShutter()` → 幕布设为 VISIBLE → **盖黑**。
3. 幕布要等到 `onRenderedFirstFrame()` 才被设成 INVISIBLE。

所以「两集之间黑一下」的窗口，就是**新一集解码器从建好到出第一帧**这段。`setKeepContentOnPlayerReset(true)` 挡不住它 —— 那一条只管「播放器 reset 时别把画面清掉」，盖黑是 `closeShutter()` 主动做的。

### 在投影仪上实测：黑的是画面本身，不是这层幕

把这块幕改成透明（只改这一行）之后装到投影仪（XGIMI，Android 8.0）上，**黑屏依旧**。

原因是：黑的是 **Surface 本身**。切集时旧解码器被释放、新解码器还没出第一帧，这段时间画面上本来就没有东西可显示 —— 幕布盖在上面还是透明，底下都是黑的。**UI 层遮黑这条路在投影仪上是死的。**

### 那这一行为什么还留着

因为它本身无害，而且不是所有盒子都一样：有的设备上 Surface 会留着上一帧的最后一张画面（`setKeepContentOnPlayerReset(true)` 管的就是这个），那时候盖着一块不透明的幕布就是多一次黑闪，透明了就只是一次「画面停住」。这一行改动的实验版在投影仪上实测过：能播、不闪退、连播正常。

### 真要根治，只剩一条路

彻底消除这个空窗，只能**在片尾之前就把下一集的解码器建好**：两个播放器并行，下一集提前 prepare，Media3 官方接口 `PlayerView.switchTargetView(player, oldView, newView)` 就是干这个的（官方注释称 "achieves a more seamless transition"）。

前提是这台盒子**允许同时跑两个视频解码器** —— 老芯片常常只给一个。所以这条路要么先在硬件上验证，要么就不做。这一版没做。

### 这一轮实验的账

排查过程中装过几个实验版（9053–9057，从未公开发布）：

| 实验版 | 改了什么 | 结果 |
|---|---|---|
| 0.9.53-dbg | 切集计时埋点 + 画面左上角读数条 + 崩溃上报 | **切集闪退** |
| 0.9.54 | 完整还原到 0.9.52 | 恢复正常，人眼确认 |
| 0.9.55-dbg | **只改遮罩那一行** | 不闪退 → 闪退是上一批埋点/读数条带来的，不是这一行 |
| 0.9.56-dbg | 只往已有 HUD 文字追加读数（无新 View、无网络） | 不闪退；预取命中，切集总耗时 **513 ms** |
| 0.9.57-dbg | 加解码器探针 | 不闪退；预取命中，切集总耗时 **580 ms** |

这一版把上面这些实验代码**全部撤掉**：计时埋点、崩溃上报、解码器探针、画面左上角的读数条，一个都不在正式包里。

## 已知边界

- **切集的黑屏没有被治好**。这一版只是去掉了「多盖一层黑幕」这件事。要根治得在片尾前预建下一集解码器，代价和硬件前提见上面那节 —— 这一版没做。
- 「遮罩透明」在投影仪上看不出差别（黑的是画面本身）。它在别的盒子上有没有用，这里没法验证。
- 切集耗时那两个数字是**带读数的实验版**量到的，那一版的埋点本身在闪退排查期间被怀疑过（后来证明闪退来自它那一批 UI 改动，而不是数字本身）。这一版不含读数，数字没有再量。
- 投影仪上没有开 adb over network（5555 直接拒连），**logcat 读不到** —— 设备上出的问题只能靠人眼看，或者让 App 自己把状态送出来。
