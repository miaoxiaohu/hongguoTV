# Kotlin 0.9.49：遥控器的选中按位置算，不再按第几个

<!-- notes -->
遥控器选中的落点改了：从屏幕左边按「下」现在落在正下方的内容上，不会再横跳到屏幕另一头。
网格第一列按左、最后一列按右不再卡住不动，会在本行内绕回另一头。
<!-- /notes -->

最低 Android 8.0 / API 26，versionCode 9049。单 APK，安装后联网使用，无需额外服务。沿用发布签名，可覆盖安装 0.9.48 并保留本机收藏、观看记录和设置。

发布页：[kotlin-v0.9.49](https://github.com/miaoxiaohu/hongguoTV/releases/tag/kotlin-v0.9.49)，安装包 `hongguotv-kotlin-0.9.49-android8.apk`。

## 遥控器为什么老是跳到别处

- **落点是「第几个」算出来的，不是「在哪儿」**：原来首页、目录页、搜索页、详情页、选集面板、设置页
  各手写一套 `nextFocus*Id`，同一个动作在不同页面落到不同的地方 —— 首页从「首页」按下键，
  焦点跳到屏幕**最右边**的片库按钮；搜索页从「手机输入」按下键，焦点落到**最左边**的第一张卡。
  数字算的是「第几个」，眼睛看的是「在哪儿」，两者对不上。
- **到头就把自己锁死**：网格第一列按左、最后一列按右，方向键被指回自己 —— 按了没反应，
  焦点卡在原地，屏幕上一点动静都没有。
- **选集面板第一行按「上」按格子下标分派**：0—2 去「上一组」、3—4 去「下一组」。纯属数下标数出来的，
  和格子在屏幕上的位置无关。
- **详情页的季度卡曾经遥控器走不到**：剧集网格末行不写「下」的落点，只能靠系统自己的几何搜索去猜，
  猜不中就永远按不到「同系列剧」（0.9.4 那一版就是因为这个被删掉的）。

## 现在怎么算

- **只有两条规则，六个页面同一套**：
  - **左右**：在同一「视觉行」里找最近的一个；到头了在本行内绕回另一头（所以永远按了有反应）。
  - **上下**：去相邻的视觉行，在那一行里挑与当前位置横向重叠最多的那个；没有重叠就挑中心离得最近的。
- **视觉行是量出来的，不是声明的**：每量一次布局就把这一屏所有可聚焦的控件按纵向位置分成行。
  首页是若干条货架、详情页是剧集网格加季度列表、设置页是左右两列 —— 行数各不相同，
  但规则只有一条，所以不用在六个地方各写一遍（写错一处不会报错，只会让焦点跳到奇怪的地方）。
- **输入框的左右键留给它自己**：输入框里按左右是移动光标，不是移动焦点；焦点图只接管它的上下。
- **落点写在控件上，不写在页面上**：`nextFocus*Id` 由焦点图统一算好写回，五个页面里手写的那套
  落点已经全部拆掉 —— 两套并存迟早又打架。
